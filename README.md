# Levine Artist Site

Minimal artist landing page for Levine built with React, Vite, and Tailwind CSS.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deploy

- Framework: `Vite`
- Build command: `npm run build`
- Output directory: `dist`

Security headers for Vercel are configured in `vercel.json`.
